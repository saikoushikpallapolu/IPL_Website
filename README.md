# IPL Auction Price Predictor

**Advanced Multi-League Auction Simulator with ML Price Prediction**

Python-based predictive model trained on 1000+ player records from 5+ major cricket leagues (IPL, PSL, BBL, CPL, CSA) using 15+ performance features to classify players as overpriced, underpriced, or fair – integrated with an interactive auction simulator validated against IPL 2025 outcomes.

## Features

- **Multi-League Dataset**: Data sourced from Kaggle covering global T20 leagues
- **ML Price Prediction**: Regression model with 15+ performance metrics
- **Interactive Auction Simulator**: Real-time auction environment
- **Validation**: Tested against actual IPL 2025 auction results
- **Player Classification**: Overpriced, Underpriced, Fair pricing tiers

## Tech Stack

- **Language**: Python
- **ML Framework**: Scikit-learn, Pandas, NumPy
- **Data Source**: Kaggle multi-league datasets
- **Simulation Engine**: Custom auction logic

## Usage

```bash
python main.py
```
